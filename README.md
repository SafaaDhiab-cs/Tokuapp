TokuApp

هو مشروع تعليمي تم تطويره باستخدام Flutter بهدف تعلم مهارات بناء تطبيقات متعددة الصفحات والتعامل مع التنقل بين الشاشات
  # الهدف من المشروع

  - تجربة تعدد الصفحات Navigation في Flutter.
  - تعلم كيفية الانتقال بين الشاشات باستخدام Navigator.
  - ممارسة استخدام Widgets و Layouts مختلفة.
  - تطوير مهارات تنظيم الكود والمشروع في Flutter.

   # مميزات المشروع التعليمية

   - الانتقال بين أكثر من صفحة داخل التطبيق.
   - تمرين على تمرير البيانات بين الصفحات.
   - استخدام AppBar و Buttons و Lists وغيرها من عناصر الواجهة.
   - تنظيم المشروع بطريقة قابلة للتطوير مع تعلم مفهوم  Stateless Widgets.
   - تنظيم المشروع بشكل واضح:
   - فصل صفحات التطبيق في مجلد screens
   - وضع Widgets القابلة لإعادة الاستخدام في مجلد widgets
   - وضع  البيانات في مجلد models
